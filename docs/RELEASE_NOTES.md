Android向け「からだの記録 / Pain Log」の正式配布版です。Android 8.0以降に対応します。

- 身体の痛み・怠さ・不快感の10段階記録。
- 14部位の複数選択と部位の自由記述。
- 腹痛・頭痛を別項目で記録。
- むくみ・じんましん・乾燥・光過敏などの記録。
- 端末内保存、履歴の編集・削除、全記録のCSV書き出し。
- 添付されたPAIN LOGデザインをもとにしたアイコン。
- ステータスバー・ホームボタン・キーボード領域への余白調整。

APKをダウンロードしてAndroid端末で開いてください。`pain-log-browser.html` はPCやスマートフォンのブラウザで操作を試すための体験版です。Android版とブラウザ版の記録は同期しません。

試験用debug APKからは署名が異なり、上書き更新できない場合があります。アンインストール前にCSVを書き出してください。CSVの再取り込み・アプリ内復元はできません。アプリの削除や端末故障で記録が失われるため、定期的なCSV保存をおすすめします。

Androidテスト・ブラウザ操作テスト・release用Lint・ビルド・署名検証が成功しました。公開後にAPKを再ダウンロードしてチェックサムと新しい署名証明書の一致を確認済みです。実機でのCSV保存先選択、Excel／Googleスプレッドシートの読み込み、各端末のナビゲーション表示は未確認です。
