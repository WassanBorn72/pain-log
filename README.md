# からだの記録 / Pain Log

<img src="docs/icon.png" width="112" alt="PAIN LOGのアイコン">

身体の痛みや体調を、毎日のペースで記録するAndroidアプリです。線維筋痛症などによる症状の振り返りや、受診時に体調を伝えるためのメモとして使えます。

アカウント登録は不要です。記録は端末内に保存され、インターネットに接続せずに使えます。診断や治療判断を行うアプリではありません。

## インストール

Android 8.0以降に対応しています。

**[Android版 v1.3.0をダウンロード](https://github.com/WassanBorn72/pain-log/releases/download/v1.3.0/pain-log-v1.3.0.apk)**

[リリース情報と全ダウンロードファイル](https://github.com/WassanBorn72/pain-log/releases/tag/v1.3.0)

APKを端末に保存して開くとインストールできます。Androidに許可を求められた場合は、ダウンロードに使ったブラウザなどに対して「この提供元のアプリを許可」を選び、インストール後は必要に応じて許可を戻してください。

## 記録する

「記録する」で日時と症状を入力し、「この内容を保存」を押します。過去の日時も選べます。

| 項目 | 入力方法 |
| --- | --- |
| 身体の痛み・怠さ・症状に対する不快感 | それぞれ1〜10段階。1が最も軽く、10が最も強い状態です。3項目は必須です。 |
| 痛む部位 | 頭・顔、首、肩、胸、背中、腰、腹部、お尻・股関節、腕・肘、手・指、太もも、膝、すね・ふくらはぎ、足首・足から複数選択できます。左右や細かい位置は補足できます。 |
| 腹痛・頭痛 | 身体の痛みとは別に「未記録／なし／1〜10段階」で記録します。 |
| むくみ・じんましん・口やのどの渇き・皮膚の乾燥・光過敏・睡眠で休めなかった | それぞれ「未記録／なし／あり」を選べます。 |
| その他自由記述 | 服薬、症状の変化、きっかけなどを自由に書けます。 |

わからない項目は「未記録」のままにできます。「履歴・書き出し」から過去の記録を確認・編集・削除できます。削除した記録は元に戻せません。

## Androidの記録をCSVに書き出す

1. Androidアプリの「履歴・書き出し」を開きます。
2. 「すべての記録をCSVに書き出す」を押します。
3. Androidの保存先選択画面で、保存するフォルダとファイル名を選びます。

**Androidアプリに保存した記録がCSVファイルに書き出されます。** 選択した部位、補足、自由記述も含まれます。

- **Excel**：保存したCSVを開きます。文字化けする場合は「データ → テキストまたはCSVから」で文字コードにUTF-8を選んでください。
- **Googleスプレッドシート**：「ファイル → インポート → アップロード」からCSVを選びます。

自動同期やGoogleアカウント連携はありません。CSVをアプリへ戻す機能もないため、書き出したCSVは閲覧・共有用として保管してください。

## 記録を守るために

記録はアプリ専用の保存領域に保存します。広告・アクセス解析・記録の外部送信はありません。端末の自動バックアップの対象にもなりません。

**アプリのアンインストール、アプリデータの消去、端末の故障・紛失で記録が失われます。** 大切な記録は定期的にCSVへ書き出してください。CSVには健康情報が含まれるため、保存先と共有相手を確認してください。

更新時はアンインストールせず、同じ配布元の新しいAPKで上書き更新してください。試験用APKから正式配布版への移行時は、署名が異なり上書きできない場合があります。先にCSVを書き出してください。CSVからのアプリ内復元はできません。

## ブラウザで試す

[ブラウザ体験版のHTML](https://github.com/WassanBorn72/pain-log/releases/download/v1.3.0/pain-log-browser.html)をダウンロードして、ChromeやEdgeなどで開くと、インストール前に操作を試せます。「サンプルを入力」から試験用の記録を作成できます。GitHubのファイル表示画面では動作しないため、ファイルを保存してから開いてください。

ブラウザ体験版の保存先は、そのブラウザ内です。**Androidアプリの記録とは同期しません。** ブラウザからのCSV出力にはブラウザ内の記録が、AndroidからのCSV出力にはAndroid内の記録が入ります。

ブラウザ設定によっては保存できず、「一時保存モード」と表示されます。体験版では試験用の内容を使い、必要な記録は閉じる前にCSVを書き出してください。
